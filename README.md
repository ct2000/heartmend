# HeartMend PWA

HeartMend is a private, offline-first breakup recovery companion. It is static HTML/CSS/JS only: no backend, no account, no tracking.

## New in v2

- Panic Room for acute emotional waves
- Stronger No Contact tracker with milestones and slip/reset support
- The Void for unsent messages
- 30-Day recovery path
- Reality / red-flag list for romanticising moments
- Compassionate accountability tracker
- Mood graph and progress evidence
- Remote Work Mode, journal, grounding, and safety page

## Hosting from iPhone

For Tiiny Host or any ZIP-based static host, upload a ZIP where `index.html` is at the top level of the archive.

## Install on iPhone

1. Open the hosted site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open HeartMend from the Home Screen once online so it can cache for offline use.

## Privacy

Your entries are saved only in the browser storage on the device you use. Use Settings → Export JSON before clearing browser data or switching devices.
